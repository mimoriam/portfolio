## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18.0 or higher recommended)
- npm or pnpm

### 1. Clone the Repository
```bash
git clone https://github.com/mimoriam/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build Production Bundle
```bash
npm run build
```
Generates an optimized, tree-shaken static production bundle in `dist/`.

### 5. Preview Production Build
```bash
npm run preview
```

## 🚀 Continuous Deployment (GitHub Actions)

This repository includes a fully automated continuous deployment pipeline ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

Every push to the `main` branch automatically triggers:
1. Fresh dependency installation (`npm ci`)
2. Production compilation & bundle optimization (`npm run build`)
3. Static artifact packaging including the `CNAME` file
4. Deployment to **GitHub Pages** with custom domain binding

To enable GitHub Pages in your fork or repository:
1. Navigate to your repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions**.
3. Push to `main`. The site is automatically live in under 60 seconds.
